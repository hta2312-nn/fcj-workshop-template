This worklog documents my 12-week internship journey (from September 14, 2026 to December 4, 2026) at **First Cloud AI Journey (FCAJ)**. Throughout the program, I progressed from mastering core AWS cloud fundamentals and serverless architecture to designing, building, hardening, and documenting an end-to-end serverless project: **AI Legal & Security Assistant for Decree 13/2023/ND-CP**.

Over the 12 weeks, I combined self-study via AWS documentation and AWS Study Group resources, hands-on labs, community tech events, technical blogging, and iterative project reviews with mentors and peers. Below is the weekly summary of my progress:

**Week 1:** [Getting acquainted with FCAJ, AWS fundamentals, account setup, AWS Budgets, and AWS Support](1.1-week1/)

**Week 2:** [Practicing IAM least privilege, Amazon S3 static website hosting, EC2 basics, and attending the "The Thinking Behind Building The Bot" talkshow](1.2-week2/)

**Week 3:** [Learning VPC networking, RDS vs. DynamoDB, AWS Lambda basics, and attending AWS Cloud Day & AI Day Watch Party and Fireside Chat with Dr. Werner](1.3-week3/)

**Week 4:** [Deepening hands-on skills with Lambda, API Gateway, CloudWatch, and DynamoDB to build a mini serverless API end to end](1.4-week4/)

**Week 5:** [Selecting the workshop topic (AI Legal & Security Assistant for Decree 13/2023/ND-CP), comparing RAG/LLM options, designing the architecture, and drafting the Proposal](1.5-week5/)

**Week 6:** [Analyzing Decree 13/2023/ND-CP, designing the role-based system prompt and RAG context rules in Groq Playground, and defining the LegalArticles schema](1.6-week6/)

**Week 7:** [Building and seeding the LegalArticles knowledge base in DynamoDB and configuring a least-privilege IAM policy and execution role for Lambda](1.7-week7/)

**Week 8:** [Developing and testing the serverless backend (Lambda, Groq API, API Gateway with CORS) and standardizing input validation and error handling](1.8-week8/)

**Week 9:** [Hardening the system with API throttling and CloudWatch alarms, testing prompt injection, verifying legal content, and estimating costs with AWS Pricing Calculator](1.9-week9/)

**Week 10:** [Building and deploying the chat frontend on Amazon S3, running end-to-end tests with a demo video, drafting the Workshop, and cleaning up all resources](1.10-week10/)

**Week 11:** [Finalizing the Proposal and Workshop with Pricing Calculator estimates and Well-Architected mapping, and publishing two technical blog posts](1.11-week11/)

**Week 12:** [Researching future security and retrieval improvements (Parameter Store, Cognito, Amazon Bedrock), publishing the third blog post, completing the final demo, Self-Assessment, and submitting all deliverables](1.12-week12/)
