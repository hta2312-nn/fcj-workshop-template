This section lists and introduces the blogs I have posted to [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj). For example:

### [Blog 1 - AWS AMPLIFY: AN INTRODUCTION AND WHY IT FITS STUDENT AND PERSONAL PROJECTS](3.1-Blog1/)
This blog introduces AWS Amplify, a toolkit that helps developers build full-stack web and mobile applications without managing cloud infrastructure or DevOps in depth. It covers the main features, including Cognito-based authentication, GraphQL and REST APIs, and CI/CD hosting, and explains why it suits demos, course projects, and MVPs, along with its limits for highly customized setups.

### [Blog 2 - AWS LEARNING CORNER: WHAT NEWCOMERS NEED TO KNOW TO AVOID A SHOCKING END-OF-MONTH BILL](3.2-Blog2/)
This blog offers practical cost-control guidance for people new to AWS. It explains how to set up AWS Budgets and billing alerts, how to use the Free Tier without exceeding its limits, which idle resources such as Elastic IPs and leftover EBS volumes can quietly generate charges, and how to use Cost Explorer to spot unusual spending early.

### [Blog 3 - AWS LEARNING CORNER: BUILDING A SIMPLE, SECURE STATIC WEBSITE WITH S3 + CLOUDFRONT + ROUTE 53](3.3-Blog3/)
This blog walks through hosting a static website on Amazon S3, delivering it globally through CloudFront with HTTPS and Origin Access Control, and pointing a custom domain to it with Route 53. It highlights the low cost, scalability, and reduced operational work of this serverless approach, and presents it as a classic exercise for combining core AWS services.
