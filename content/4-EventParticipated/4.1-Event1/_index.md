# Summary Report: “ The Thinking Behind Building The Bot”

## Event Objectives

The event aimed to provide participants with a practical perspective on AI Agents and AI-powered applications. Instead of focusing only on AI technology itself, the talkshow introduced the way developers think about real-world problems when building AI-powered bots.

The event also provided an opportunity to learn from experienced developers and technical leaders, understand how AI is being applied in enterprise environments, and gain insights into career opportunities in the technology industry.

## Speakers

* Thien Lu – Program Manager, First Cloud AI Journey (FCAJ)
* Truong Bui – Tech Lead, CMC Global
* Phong Pham – Program Manager, First Cloud AI Journey (FCAJ)

## Key Highlights

### Understanding AI Agents

One of the main topics of the event was AI Agents and how they can be used to build applications that are more capable of handling real-world tasks.

The discussion helped me understand that building an AI-powered bot is not simply about connecting an application to an AI model. Developers also need to think about the problem that the bot is solving, how users interact with it, and how the system should process information and respond.

### Real-World Programming Problems

The event connected AI concepts with practical programming situations. This showed how developers need to consider actual user and business requirements instead of focusing only on the technical capabilities of AI.

I learned that a good AI solution should begin with a clearly defined problem and then determine how AI can provide value to the users.

### The Thinking Behind Building a Bot

The most interesting part of the event was understanding the thought process behind building an AI bot.

Rather than immediately selecting technologies, developers should first consider:

* What problem does the bot need to solve?
* Who will use the bot?
* What information does the bot need?
* What should the bot be able to do?
* How should the bot respond to different situations?
* How can the system be designed to work reliably in a real environment?

This changed my perspective from simply "using AI" to designing a complete AI solution around a specific problem.

### Enterprise Perspective

The event also provided a perspective from CMC Global about how AI can be applied in a professional environment.

This helped me understand that enterprise AI applications need to consider not only functionality but also practical requirements such as reliability, security, scalability, and the actual business value provided by the system.

### Career and Industry Insights

At the end of the event, participants also had opportunities to interact with representatives from CMC Global regarding career opportunities, interviews, and professional development.

This gave me a better understanding of the skills that developers should develop when preparing to work in an AI-related software engineering environment.

## Key Takeaways

Technical Perspective

* AI Agents can be used to create applications that perform more complex tasks than traditional chatbot systems.
* Building an AI application requires more than selecting an AI model.
* The AI component needs to be integrated into a complete application and workflow.
* Real-world AI systems should consider reliability, security, scalability, and user requirements.

Problem-Solving Mindset

The biggest lesson I gained from the event was to start with the problem rather than the technology.

Before choosing AWS services or AI models, developers should understand the business requirements and define what the system actually needs to accomplish.

Breaking a complex problem into smaller components also makes it easier to design and implement the solution.

### Career Perspective

The event also showed me that AI development requires a combination of different skills. Understanding AI is important, but software development fundamentals, problem-solving, system design, and the ability to understand business requirements are also necessary.

### Applying to My FCAJ Project

The knowledge from this event can be directly applied to my FCAJ project, which focuses on building an AI assistant for enterprise legal and security information.

Before attending the event, I mainly focused on identifying which AWS services could be used, such as Amazon Bedrock, Amazon S3, AWS Lambda, API Gateway, and DynamoDB.

After the event, I realized that the more important first step is to clearly define the problem that the system needs to solve.

For example, an enterprise user could describe a security or legal incident to the AI assistant. The system would then use the organization's internal knowledge base to analyze the situation and provide relevant information.

This approach helps me think about the project from the business use case first, and then determine how AWS services and AI technologies should be used to implement the solution.

## Event Experience

### Learning from Experienced Speakers

The event allowed me to learn from technical leaders and program managers who have experience working with technology and AI projects. Their perspectives helped me better understand how AI solutions are approached in real-world environments.

### Understanding Real-World AI Development

Instead of learning AI only from theoretical materials, the event showed how developers need to think about practical problems when creating AI-powered applications.

This helped me connect the AI concepts I am studying with actual software development.

### Problem-Solving and Technical Thinking

The event encouraged me to think more carefully about the reasoning behind an AI solution. I learned that choosing a technology should come after understanding the problem and requirements.

This is particularly useful for my FCAJ project because AWS provides many different services, and choosing a service should be based on the actual requirements rather than simply using as many services as possible.

### Career Discussion

The career discussion with CMC Global also gave me an opportunity to learn more about the expectations of companies in the technology industry.

It encouraged me to improve not only my technical knowledge but also my ability to explain projects, solve problems, and work effectively as part of a team.

## Lessons Learned

The most important lesson I gained from the event is that building an AI solution is not simply about using a powerful AI model.

A useful AI application requires a clear problem, a suitable workflow, appropriate data, good system design, and consideration of real-world requirements.

This mindset will help me approach my FCAJ project more systematically and make better decisions when selecting AWS services and designing the AI workflow.
