# Summary Report: “AWS CLOUD & AI DAY 2026: HCMC WATCH PARTY”

## Event Objectives

AWS Cloud and AI Day Hanoi is a one-day event designed to bring AWS expertise, cloud technologies, and AI innovations directly to developers, IT professionals, business leaders, and technology enthusiasts.

The event focuses on helping participants understand how cloud computing and AI can be applied to real-world business and technical challenges. The main topics include Agentic AI, data analytics, cloud migration, industry solutions, and modern application development.

The event also provides opportunities for participants to learn from AWS experts, explore real-world customer experiences, and understand current trends in cloud and AI technology.

## Key Highlights

### Agentic AI

One of the major topics of the event is Agentic AI, which represents an important direction in the development of AI applications.

The topic provides a broader perspective on how AI can move beyond simple question-and-answer interactions and become part of systems that can assist users in performing more complex tasks.

Data Analytics

The event also focuses on data analytics and the role of data in modern cloud-based applications.

I learned that data is an important foundation for AI and business applications. Organizations need appropriate ways to collect, process, analyze, and use data before they can effectively take advantage of AI technologies.

Cloud Migration

Another important topic is cloud migration.

The event provides insights into how organizations can move existing infrastructure and applications to the cloud while considering factors such as scalability, cost, reliability, and modernization.

This helped me understand that cloud migration is not simply moving an existing system from physical servers to AWS. Organizations also need to consider whether applications should be modernized during the migration process.

Modern Application Development

The event also introduces modern approaches to application development using cloud technologies.

Modern applications need to be designed with factors such as scalability, flexibility, availability, and efficient resource usage in mind.

This is particularly relevant to my AWS learning because understanding these principles helps me make better decisions when selecting AWS services for a project.

### Industry Solutions

The event also presents perspectives from organizations and businesses that are applying cloud and AI technologies in real-world environments.

These examples helped me understand that AWS technologies are not limited to technical experiments. They can be applied to solve practical problems across different industries.

## Key Takeaways

### Cloud and AI Are Connected

One of my main takeaways from the event is that cloud computing provides an important foundation for AI applications.

AI systems require computing resources, data storage, networking, security, and scalable infrastructure. Cloud platforms such as AWS provide these capabilities and allow organizations to build and deploy AI applications more efficiently.

### Start from the Business Problem

Another important lesson is the importance of understanding the business problem before choosing technology.

Instead of immediately deciding which AWS service to use, developers should first understand:

* What problem needs to be solved?
* Who are the users?
* What data is required?
* What does the system need to accomplish?
* What technical and business constraints exist?

Only after answering these questions should the appropriate cloud and AI technologies be selected.

### Modernization Is More Than Migration

I also learned that cloud migration can be an opportunity to modernize an existing application, rather than simply moving the same architecture to another environment.

This can involve adopting managed services, serverless technologies, modern application architectures, and AI capabilities where appropriate.

### Applying to My FCAJ Project

The knowledge from AWS Cloud and AI Day Hanoi can be applied directly to my FCAJ project, which focuses on developing an AI assistant for enterprise legal and security information.

The event reinforced my understanding that I should begin by defining the business problem rather than selecting AWS services first.

For example, the system needs to allow an enterprise user to provide information about a legal or security situation and receive an AI-generated response based on the organization's internal knowledge base.

From this requirement, I can then determine the appropriate AWS architecture.

For example:

* Amazon S3 → store internal documents and knowledge sources
* Amazon Bedrock → provide AI and foundation-model capabilities
* AWS Lambda → execute application logic
* Amazon API Gateway → provide APIs for the application
* Amazon DynamoDB → store application and conversation data

The event also helped me recognize the importance of designing the system for security, scalability, and responsible use of enterprise data, because the project involves potentially sensitive organizational information.

## Event Experience

### Learning from AWS Experts

The event provided an opportunity to learn about current developments in cloud and AI directly from AWS experts and industry leaders.

Listening to different speakers also helped me understand cloud and AI from multiple perspectives, including technology, business, and product development.

### Exploring Current AI Trends

The discussion around Agentic AI was particularly interesting because it showed how the role of AI is evolving.

Rather than treating AI only as a chatbot or question-answering tool, I began thinking more about how AI can become part of a larger application workflow.

### Understanding Enterprise Cloud Adoption

The real-world perspectives from companies such as Techcombank and Katalon helped me understand that cloud and AI adoption involves more than technical implementation.

Organizations also need to consider business value, security, scalability, cost, and the impact on existing systems.

## Lessons Learned

The most important lesson I gained from AWS Cloud and AI Day Hanoi is that cloud and AI technologies should be treated as tools for solving real problems rather than technologies that should be used simply because they are new.

The event encouraged me to approach my FCAJ project from a more practical perspective: first understand the problem and requirements, then design the architecture and select the appropriate AWS services.
